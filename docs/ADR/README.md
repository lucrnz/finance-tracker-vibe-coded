# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records documenting significant technical decisions
made in the Finance Tracker project.

## What is an ADR?

An ADR is a short document that captures an important architectural decision along with its
context and consequences. ADRs help future contributors understand why certain decisions were made.

## ADR Format

Each ADR should follow this template:

```markdown
# ADR-NNNN: Title

## Status
[Proposed | Accepted | Deprecated | Superseded]

## Context
What is the issue that we're seeing that is motivating this decision or change?

## Decision
What is the change that we're proposing and/or doing?

## Consequences
What becomes easier or more difficult to do because of this change?
```
